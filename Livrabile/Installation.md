# Silent Signal 📡

## 🚀 Tech Stack

-   React Native
-   Expo
-   JavaScript / TypeScript

------------------------------------------------------------------------

## 📋 Prerequisites

Before running the project, make sure you have the following installed:

-   Node.js → https://nodejs.org/
-   Expo CLI → https://docs.expo.dev/get-started/installation/
-   A code editor (recommended: VS Code)
-   Expo Go (optional, for running on your phone)

------------------------------------------------------------------------

## ⚙️ Getting Started

### 1. Clone the repository

git clone https://github.com/Fanebalauru/I-N-dev

### 2. Navigate to the project directory

cd I-N-dev

### 3. Install dependencies

npm install

------------------------------------------------------------------------

## ▶️ Running the App

npm start

or

npx expo start

------------------------------------------------------------------------

## 📱 Running the App

### On your phone

-   Install Expo Go
-   Scan the QR code

### On emulator

-   Press 'a' for Android
-   Press 'i' for iOS (Mac only)
